## 二、 深度拆解：3 个必改的工程与商业盲区

### 1. 盲区一：平台抽成不是“前端传参”，必须先跑一次链上 `CreatePlatformConfig`

在 Raydium LaunchLab 架构中，第三方团队建独立发射台的标准姿势是调用 `create_platform`（即 `CreatePlatformConfig`）在链上注册一个专属的 **Platform PDA**：

* **链上配置字段**：你在注册该 PDA 时，写入 `platform_fee_destination`（你的收款钱包）、`platform_fee_bps`（曲线阶段平台抽成，2026 年 8 月底协议更新后上限为 500 bps 即 5%）、`creator_fee_rate`（曲线阶段创作者分成）以及毕业迁移时的 LP 锁仓比例（`platform_scale` / `creator_scale` / `burn_scale`）。
* **重要协议变更提醒**：根据 Raydium 2026-08-17 的升级规则，代币毕业进 CPMM 池时，`platform_scale + creator_scale` 会合并铸造为**一张归属于平台（`platform_nft_wallet`）的锁定 LP Fee Key NFT**（代表永久提取锁定 LP 手续费的权利），而毕业后的创作者分成则由 CPMM 的 `AmmConfig.creator_fee_rate` 与 `platform_cp_creator` 字段控制。
* **修正方案**：必须在启动包的 `d01` 阶段增加一个 **管理员一次性链上注册脚本（`scripts/init-platform.ts`）**，生成你的 `NEXT_PUBLIC_PLATFORM_CONFIG_ID`；前端发币和买卖时全部传入这个 PDA 公钥，才能真正把过路费收到你自己的钱包。

### 2. 盲区二：xStocks 计价资产的 `GlobalConfig` 限制与“双层抽成”破局

为什么 StonkFun 能支持 507 种计价资产？

* 一方面，StonkFun 早期及部分特殊交易对直接调用了 Raydium CLMM 的 `create_customizable_pool`（单边集中流动性池，无需 Bonding Curve 即可模拟递增价格）；
* 另一方面，在 LaunchLab 路径下，每一个可用的计价资产都对应链上一个特定的 `GlobalConfig` 账户，并且发币时需要根据计价资产当时的美元价格动态换算 `total_quote_fund_raising`（毕业募资额，比如把固定美元门槛折算成对应数量的 `SPYx` 或 `SOL`）。
* **更大的痛点与暴利机会**：想买“锚定英伟达（`NVDAx`）的 Meme 币”的散户，钱包里 99% 只有 `SOL` 或 `USDC`，根本没有 `NVDAx`！
* **修正方案（一石二鸟）**：
1. 让 Agent 在后端通过读取链上已有的 `GlobalConfig` 列表（包括复用 StonkFun/Raydium 已在链上跑通的 `GlobalConfig` 账户）来生成前端可选的计价资产白名单；
2. 在交易页植入 **“SOL 一键跨资产买入（Zap-In）”**：当散户用 `SOL` 购买锚定 `xStocks` 的新币时，先调 **Jupiter Swap API v1** 将 `SOL` 闪兑为对应的 `xStocks`（此处挂载 `platformFeeBps=80` 收第一道 **0.8% 换汇路由费**），再把换出来的 `xStocks` 喂给 LaunchLab 曲线（收第二道 **0.5% 发射台平台费**）。这不仅消除了散户手里没有股票代币的最大摩擦，还让你的单笔抽成直接翻倍！



### 3. 盲区三：如何解决“克隆站上线即鬼城”？（借壳冷启动策略）

如果你做出来的“发射数据终端”只显示你自己 `PlatformConfig` 下面发出来的币，上线第一天页面是空的，没人会来玩。

* **修正方案**：因为 StonkFun 和 LetsBonk.fun 的新币全都跑在同一个 `raydium_launchpad` 程序上！
* 你的第五个模块“发射数据终端”在读取链上数据时，**默认展示全网 `raydium_launchpad` 上的热门 xStocks 锚定币（含 StonkFun 的活跃池）**，同时把你平台自己发的币置顶高亮（打上 `🔥 0% 转账税 · 纯净版` 标签，精准打击 StonkFun 饱受诟病的 1%~3% 转账税砸盘痛点）。
* 当用户在你的终端里看中了 StonkFun 的某个热门币并点击买入时，走你上面那套 **Jupiter Zap-In（SOL → xStocks）路由** 或 **毕业后 CPMM 池的 Jupiter 抽成路由**。这样你不需要等别人来你这发币，**上线第一分钟就能直接从 StonkFun 每天上千万美元的存量交易盘子里截流抽水！**
